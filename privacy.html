سياسة الخصوصية وبيان استخدام البيانات

آخر تحديث: 22 نوفمبر 2026

توضح هذه الصفحة كيف تتعامل العزم العالمية للعقارات مع المعلومات التي يرسلها الزائر عبر نموذج الطلب العقاري. إرسال الطلب لا ينشئ عقد وساطة أو التزاماً بإتمام صفقة.

1. البيانات التي نجمعها

قد نحفظ الاسم ورقم التواصل والدولة والمدينة ونوع الطلب وفئة العرض (عقارات أو محلات أو سيارات أو دراجات نارية) والميزانية التقريبية ووقت التواصل ولغة التواصل المفضلة والتفاصيل التي يختار الزائر كتابتها، إضافة إلى حالة موافقته على التواصل.

2. لماذا نستخدم البيانات؟

  • فهم طلب الشراء أو البيع أو الاستئجار أو التأجير أو الشراكة.
  • التواصل مع صاحب الطلب للرد على استفساره وتوضيح الخطوات التالية.
  • تنظيم الطلب ومتابعته داخلياً وإحالته إلى موظف أو شريك عقاري مخوّل عند الحاجة.

3. المشاركة والإفصاح

لا نبيع بيانات العملاء. ولا نشارك بيانات التواصل مع مالك عقار أو وسيط أو شريك خارجي إلا بالقدر اللازم لمتابعة الطلب وبما يتفق مع موافقة صاحب البيانات والأنظمة المعمول بها. وقد تعالج البيانات عبر مزودي خدمات الاستضافة وقواعد البيانات اللازمة لتشغيل الموقع.

4. الحفظ والأمان

نستخدم ضوابط وصول وقاعدة بيانات محمية لتقليل الوصول غير المصرح به. نحتفظ بالمعلومات للمدة اللازمة لمتابعة الطلب والوفاء بالالتزامات التشغيلية أو النظامية، ثم نراجع الحاجة إلى استمرار الاحتفاظ بها. لا ترسل كلمات مرور أو أرقام بطاقات أو وثائق هوية أو معلومات مالية حساسة عبر النموذج.

5. خيارات صاحب البيانات

يمكن لصاحب الطلب طلب الاطلاع على بياناته أو تصحيحها أو حذفها، أو سحب موافقته على التواصل، عبر التواصل مع الشركة. سنراجع الطلب ونتعامل معه وفق المتطلبات القانونية المطبقة وأي التزامات نظامية للاحتفاظ بالسجلات.

6. التواصل

للاستفسارات المتعلقة بالخصوصية أو لطلب تعديل البيانات أو حذفها، تواصل عبر واتساب الشركة: +967 711 273 188.

7. نطاق التطبيق

تقدم الشركة خدماتها أو تنسق فرصاً في أسواق متعددة، وقد تختلف المتطلبات القانونية بحسب الدولة. هذه الصفحة بيان عام للخصوصية وليست بديلاً عن أي إشعار أو التزام قانوني محلي مطلوب في سوق معين. قد يتم تحديثها عند تغير طريقة جمع البيانات أو استخدامها.
