# AL AZM GLOBAL REAL ESTATE

الموقع التعريفي الرسمي لشركة العزم العالمية للعقارات.

## الملفات
- `index.html`: صفحة عربية متجاوبة (RTL) مع أنماط CSS داخلية.

## النشر على Netlify
1. افتح https://app.netlify.com/
2. اختر **Add new site** ثم **Import an existing project**.
3. اربط GitHub واختر المستودع `alazm-global-real-estate`.
4. اختر الفرع `main`.
5. اترك **Build command** فارغاً.
6. اجعل **Publish directory** هو `.`.
7. اضغط **Deploy site**.

## ملاحظات
- لا توجد عقارات معروضة حالياً؛ لا تضف إعلاناً إلا بعد الحصول على إذن المالك والتحقق من المعلومات.
- الصفحة تعريفية ولا تثبت وجود ترخيص عقاري في أي دولة.
- لا تضع مفاتيح API أو كلمات مرور أو بيانات حساسة في هذا المستودع العام.
